# Silent aim: отдельный экспериментальный модуль

Старый чит, DLL и дампы сохранены без изменений. Этот модуль работает отдельно через Frida с уже запущенным Windows x64 процессом. Новый дамп и отдельный файл `global-metadata.dat` не требуются: сведения о классах, полях и сигнатурах берутся через IL2CPP API процесса.

## Реализовано в исходниках

- Поиск `ShotArgsModel.Set`, `PlayerShotsUpdater.Update` и `UnityEntry.Update` по именам в текущем runtime.
- Проверка платформы, SHA-256 загруженной DLL, сигнатур, параметров `position`/`direction`, размера Vector3 и исполняемого диапазона адресов.
- Привязка модели выстрела к updater локального игрока через его Id. Обработка идёт в потоке, наблюдаемом в `UnityEntry.Update`.
- Сбор активных `BattleCharacterEntityView` и положения головы. Собственный персонаж исключается по расстоянию до позиции локального игрока. Радиус исключения 2 метра также исключает близко стоящих чужих персонажей.
- Выбор головы с наименьшим углом к исходному направлению в пределах FOV и дистанции. FOV — полный угол конуса.
- Проверка препятствий через `Physics.Raycast`; используется проверка до точки за 0.5 метра перед головой, с игнорированием trigger-коллайдеров.
- Подмена только аргумента направления текущего вызова `Set`: указатель перенаправляется на отдельный 12-байтный вектор. Поворот камеры не меняется.
- Истечение snapshot через 250 мс, отключение при ошибке, удаление собственных хуков при штатном завершении.

Модуль нацелен на присланную GameAssembly.dll с SHA-256 `03003754353ff08380dc8e91920f2c77f7977b370d413083acfe9b4bc65c18ab`. Несовпадение DLL или сигнатур останавливает установку.

## Запуск позднее на Windows

Нужен работающий процесс с инициализированным IL2CPP, допускающий подключение Frida.

```powershell
python -m pip install frida
Get-Process | Where-Object ProcessName -eq 'ROB RUN' | Select-Object Id, ProcessName
python .\run.py --pid 1234
```

Указать настоящий Id вместо `1234`. После сообщения `installed` модуль по умолчанию выключен. Управление в его консоли:

```text
on
status
fov 10
distance 200
off
quit
```

Счётчик `redirects` показывает число подмен аргумента, а не число попаданий или нанесённый урон. Запуск с `--enabled` сразу разрешает подмены после успешных проверок. Это отдельный модуль с консольным управлением; переключатель в существующем ImGui-меню не добавлен.

## Что ещё требует проверки

Реальные вызовы IL2CPP, ABI аргументов, порядок обновления модели выстрела и результат на сервере в облаке не проверялись. Изменение `ShotArgsModel.Set` может влиять только на часть пути выстрела или клиентское предсказание; влияние на фактическое попадание не подтверждено. Inlining также может привести к отсутствию перехваченных вызовов.

Список кандидатов включает активные view; фильтрации союзников и умерших чужих персонажей пока нет. Уменьшение луча на 0.5 метра является приближением проверки препятствий, без подтверждения hitbox цели. Другие коллайдеры могут отклонять подходящих кандидатов. Методные имена и параметры проверяются при запуске, при несовпадении модуль останавливается.

Модуль не меняет EAC и не устанавливает драйверы. Процесс может отклонить подключение Frida; это отдельная непроверенная зависимость окружения. Старые инструкции запуска из проекта не являются частью этого модуля.
