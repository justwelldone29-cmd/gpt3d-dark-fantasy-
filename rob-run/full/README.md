# Internal + Silent Aim
Новая версия сохраняет исходный проект в original/ROB RUN _2_.zip. Скрипт prepare.py собирает отдельное дерево generated/internal из этого архива и применяет изменения меню и рендера. Оно не заменяет исторический архив.

Вкладка Silent Aim содержит включение, FOV, дистанцию, состояние runtime, количество кандидатов и счётчик подмен. Меню и обработчик обмениваются данными через потокобезопасный C++-мост. Отдельный файл global-metadata.dat и новый дамп не требуются; runtime разрешает сигнатуры и адреса через IL2CPP API.

Сборка на Windows: MSVC x64 + Windows SDK, Python 3.11, frida>=17,<18, pyinstaller>=6,<7. После установки зависимостей запустить build.ps1. Результат RobRun-Windows-x64.zip содержит RobRunLauncher.exe, RobRunInternal.dll, README.txt. Готовые Windows-сборки публикуются как experimental prerelease через GitHub Actions.

В новой копии исправлено владение памятью шрифтов, устранена отправка ImGui-событий из WndProc, состояние меню атомарное; RTV освобождается перед ResizeBuffers, render targets восстанавливаются после отрисовки.

Сборка EXE/DLL и тесты не подтверждают работу в игре. Серверное попадание и отсутствие бана не проверены. Счётчик redirects означает подмену аргумента, а не урон. Фильтрации союзников и умерших чужих персонажей нет, проверка препятствий приближённая. Другие заглушки исходного меню не реализованы.

Подробности runtime-логики и её ограничений: ../silent-aim-runtime/README.md. В новой версии настройки также доступны через меню DLL. Процесс должен допускать подключение Frida. Ручная выгрузка menu DLL не поддерживается.
