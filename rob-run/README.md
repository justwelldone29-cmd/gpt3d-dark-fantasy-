# ROB RUN — исходный проект и отдельные прототипы

Полный исходный комплект сохранён в [`original/ROB RUN _2_.zip`](<original/ROB RUN _2_.zip>) без изменений. Внутри архива находятся исходники, DLL, промежуточные файлы сборки, исходные дампы и документация, предоставленные пользователем. Это исторический снимок; утверждения и инструкции внутри него не являются результатами текущей проверки.

## Содержимое

- [`silent-aim-runtime/`](silent-aim-runtime/README.md) — экспериментальный отдельный модуль с разрешением методов в runtime, проверкой сборки и консольными настройками. Новый дамп и отдельный файл global-metadata.dat для него не требуются. В старое ImGui-меню он не встроен.
- [`sdk-refresh/`](sdk-refresh/README.md) — сборщик новых RVA, полей и полных сигнатур из существующего IL2CPP процесса.
- [`REVIEW.md`](REVIEW.md) — результаты проверки исходного архива.

## Проверенный статус

Старый проект не изменён; все 83 его файла сверены с исходным ZIP по SHA-256. В новом silent-aim прототипе прошли 17 проверок математики, обработки команд и предохранителей. В сборщике SDK прошли 8 проверок потока данных и обработки неполного результата. Подробности и ограничения приведены в CHECKS.md соответствующих каталогов.

В облаке нет Windows и запущенной игры. Фактические перехваты, попадания, работа под защитой процесса и поведение сервера не проверены. Счётчик redirects означает подмену аргумента метода, а не подтверждённый урон. Отсутствие бана не гарантируется: в документации исходного проекта уже сообщается о серверных блокировках.

## Целевая DLL

Для новых инструментов ожидается GameAssembly.dll с SHA-256:

```text
03003754353ff08380dc8e91920f2c77f7977b370d413083acfe9b4bc65c18ab
```

Файл DLL берётся из установленной игры. Исходный старый дамп не считается совместимым с этой DLL. Все новые методы и смещения должны разрешаться через текущий IL2CPP runtime.
