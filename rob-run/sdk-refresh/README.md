# Переснятие SDK без отдельного global-metadata.dat

Старый проект ROB RUN и его дампы не изменены. Это отдельный сборщик; он читает сведения о классах из уже инициализированного IL2CPP через экспортированные API. Файл `global-metadata.dat` отдельно не нужен.

## Что подготовлено

- Сбор полей, актуальных RVA, возвращаемых типов, имён и типов параметров, флагов и metadata tokens.
- Проверка SHA-256 загруженной DLL по файлу на диске. Ожидаемая DLL — присланная пользователем, SHA-256 `03003754353ff08380dc8e91920f2c77f7977b370d413083acfe9b4bc65c18ab`.
- Новый результат `full_sdk.current.jsonl` и файл с его SHA-256 `full_sdk.current.manifest.json`.
- При ошибке, обрыве или несовпадении количества записей временный результат удаляется. Существующий выходной файл не перезаписывается.
- Сборщик не запускает и не завершает игру, не загружает DLL в игру, не меняет её код и не подключает AC-заглушки. Для вызова экспортов он использует агент Frida, подключённый к существующему процессу.

## Запуск на Windows

Требуются Python, `frida` и уже запущенный процесс с инициализированным IL2CPP, допускающий подключение инструмента. Подключение может быть запрещено защитой процесса; такой случай сборщик сообщает как ошибку.

```powershell
python -m pip install frida
Get-Process | Where-Object ProcessName -eq 'ROB RUN' | Select-Object Id, ProcessName
python .\collect.py --pid 1234
```

Вместо `1234` указать фактический Id процесса. Дождаться строки `Saved:`. Для повторного запуска задать другое имя результата:

```powershell
python .\collect.py --pid 1234 --out .\full_sdk.current-2.jsonl
```

Результат предназначен для анализа; старый `dump/full_sdk.jsonl` автоматически не заменяется. Передать JSONL и соответствующий manifest для проверки и дальнейшего обновления проекта. Для другой целевой DLL предусмотрен `--expected-sha256`, который должен соответствовать её фактическому SHA-256.

## Формат

Поля `a`, `n`, `p`, `f`, `m` имеют прежний формат. Массив `signatures` расположен в том же порядке, что и `m`, и содержит объекты с `return_type`, `parameters`, `flags`, `implementation_flags`, `token`, `name`, `rva`. RVA вне диапазона GameAssembly.dll сохраняется как 0, а не как обёрнутое 32-битное число. Родительский класс обозначается полным именем, как в старом формате.

## Границы проверки

В облаке нет Windows и запущенной игры. Проверяются синтаксис агента и обработка потока данных, целостности и ошибок в Python. Реальное выполнение вызовов IL2CPP и полнота дампа на игре требуют отдельной проверки. Свежий дамп и silent aim пока не созданы.
